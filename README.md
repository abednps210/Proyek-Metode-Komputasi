Program yang dibuat adalah kalkulasi magnitudo, dimana program bekerja dengan mengambil informasi gelombang gempa dari file mseed dan data stasiun perekam gempa dari file xml yang kemudian informasi tersebut digunakan untuk menghitung magnitud lokal, magnitudo badan dan magnitudo permukaan.
Program kalkulasi ini ditampilkan dalam Guide User Interface (GUI) menggunakan modul tkinter, dimana pengguna dapat menginput lokasi kejadian dan kedalaman gempa untuk mendapatkan hasil perhitungan magnitudo. Pengguna juga dapat menampilkan plot gelombang gempa yang direkam oleh masing-masing stasiun.

*Note : saat ini program hanya dibuat untuk menghitung magnitudo gempa yang terjadi di Mindanao, Filipina pada 10 Oktober 2025*
